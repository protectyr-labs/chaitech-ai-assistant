# Brand Workshop · Resources

> Printable workbooks and a filled example for the [Brand Workshop skill](../../skills/brand-workshop/).

## What's here

| File | What it is | Who it's for |
|---|---|---|
| [`workbook.html`](workbook.html) | Empty printable workbook — same nine exercises, on paper. | Founders who want to do the workshop without Claude, or print and fill in by hand during a live session. |
| [`workbook-filled-example.html`](workbook-filled-example.html) | A fully filled example for a fictional brand ("Lumen Coffee Roasters"). | Anyone who wants to see what a finished workbook looks like before starting their own. |
| [`facilitator-guide.md`](facilitator-guide.md) | A guide for cohort leads, mentors, and accelerator program managers running the workshop with a group. | Facilitators. |

## How to use these alongside the skill

- **Solo founder, Claude-native:** Skip these resources. Run `/brand-start` from the [skill](../../skills/brand-workshop/) directly.
- **Solo founder, paper-first:** Print `workbook.html`. Fill it in by hand. When you're done, paste each section into Claude (or hire someone to type it in), then run `/brand-export` to get a clean digital deck.
- **Cohort facilitator:** Read `facilitator-guide.md`. Print `workbook.html` for participants. Use the filled example as a "what good looks like" reference at the start of the session.
- **Skeptical reviewer:** Open `workbook-filled-example.html` in your browser to see what the workshop produces before you commit to running it.

## Origin

This workshop's exercise sequence and language are adapted with credit from the public **"Brand DNA: The Art of Brand Positioning and Purpose"** webinar by Barry Hillier (barryhillier.com) and Brian Hickling (Catalyst 17). Roger Martin's *Playing to Win* strategic cascade is woven into Exercise 7. Optional Exercises 9 and 10 use Brian Hickling's published thinking on values and brand movement.

The Claude Code skill, the printable HTML, and the filled example were assembled and contributed under MIT license. Original workshop authorship belongs to Hillier and Hickling.
